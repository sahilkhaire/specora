# Traceability Matrix

## Objective
Map milestones to implementation artifacts and verification.

## Matrix

1. M2 Core Engine Stable
- Artifacts: packages/core
- Verification: core tests + lint + build

2. M3 Web Navigation and Detail Stable
- Artifacts: apps/web spec ingest, operation list/detail
- Verification: web component tests + lint + build

3. M4 CLI Workflow Replacement Stable
- Artifacts: packages/cli validate/export/serve/proxy
- Verification: CLI integration tests + lint + build

4. M6 Release Candidate and Launch
- Artifacts: release docs, changelog, quality gates
- Verification: full workspace lint/build/test and release checklist signoff
