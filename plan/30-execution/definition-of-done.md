# Definition of Done

A backlog item is done only if all conditions below are met.

## Engineering Completion

1. Implementation complete with no TODO placeholders.
2. Code respects package boundaries and coding standards.
3. Error handling is explicit and user-visible where relevant.

## Verification Completion

1. Unit/integration/component tests added or updated.
2. npm run lint passes.
3. npm run build passes.
4. npm run test passes.

## Documentation Completion

1. README updated if user-visible behavior changed.
2. Relevant plan docs updated if scope or milestones changed.
3. Release checklist updated for release-impacting work.

## Review Completion

1. Pull request includes summary and validation steps.
2. Risk impact reviewed for non-trivial architecture or scope changes.
3. No unresolved critical review comments.
