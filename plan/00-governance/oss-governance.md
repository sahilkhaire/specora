# OSS Governance

## License
- Apache-2.0

## Repository Standards
1. Use feature branches and pull requests.
2. Require at least one review before merge.
3. Keep changes scoped and documented.

## Issue Triage
1. Severity labels:
- `severity:critical`
- `severity:high`
- `severity:medium`
- `severity:low`

2. Type labels:
- `type:bug`
- `type:feature`
- `type:docs`
- `type:chore`

3. Priority labels:
- `priority:p0`
- `priority:p1`
- `priority:p2`

## Contribution Workflow
1. Fork and branch from `main`.
2. Follow setup in README.
3. Add/update tests when behavior changes.
4. Include problem statement and validation steps in PR.

## Maintainer Responsibilities
1. Keep roadmap current.
2. Review PRs with consistency and stability focus.
3. Maintain release cadence and changelogs.
4. Support respectful and inclusive contributor interactions.

## Decision Process
1. Small changes: maintainer review + merge.
2. Medium architecture changes: ADR discussion in issue.
3. Major scope change: roadmap vote among maintainers.
